# 🎬 Netflix Clone

A Netflix-inspired frontend project built using HTML, CSS, and JavaScript.

### Features

* Responsive Netflix-style UI
* Movie/show cards
* Navigation bar
* Search interface
* Hover effects
* Dark theme

### Tech Stack

* HTML5
* CSS3
* JavaScript

### Purpose

Built for frontend development practice and to improve HTML, CSS, JavaScript, and Git/GitHub skills.

> Educational project only. Not affiliated with Netflix.
